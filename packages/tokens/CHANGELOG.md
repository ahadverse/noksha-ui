# @prism-ui/tokens

## 0.1.0

### Minor Changes

- First public release.

  Twenty-two accessible React components on Tailwind CSS v4, themed from a single seed colour through
  an OKLCH engine. Components ship prebuilt with `"use client"` stamped on and per-component entry
  points; the stylesheet registers its own sources, so a consumer adds one CSS import and nothing else.
